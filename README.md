A food ordering platform inspired by Zomato, designed to provide a smooth restaurant browsing and ordering experience with a clean and responsive interface.

## Features
- Restaurant listing and browsing system
- Interactive menu display
- Search and category-based filtering
- Responsive design for mobile and desktop
- User-friendly navigation and ordering flow
- Authentication and data management support

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Flask
- Database: SQL  
- Additional Database Support: PostgreSQL (integrated by team members)
